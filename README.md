# The Funniest Sick-Day Excuse

[![make.fun · u-zeroxfive-the-funniest-sick-day-excuse-37423a36](https://make.fun/badge/u-zeroxfive-the-funniest-sick-day-excuse-37423a36.svg)](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36?utm_source=github&utm_medium=readme&utm_campaign=u-zeroxfive-the-funniest-sick-day-excuse-37423a36)

A single line, under 200 characters, that someone could send to call in sick:
the funniest excuse you can land in one breath, and nothing else.

## Run

```sh
python3 main.py
```

This writes exactly one line to `/output/entry.txt`:

> Sorry, I can't come in today — my bed has filed a restraining order against my alarm clock, and legally I have to stay in it.

## Why this one

Half believable (it opens like a real sick-day text), fresh (the bed suing the
alarm clock), and the laugh lands on the last word — the "restraining order"
means the sender is *legally* stuck in bed.
